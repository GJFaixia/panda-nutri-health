熊猫营养健康
> 熊猫主题食养健康 App｜基于 JoyCode

## 📌 项目简介
本项目是一款面向大众的食品健康智能应用，以国宝熊猫作为品牌形象，寓意温和、天然、健康。产品依托《中国居民膳食指南》与地中海饮食模式，结合 AI 实现智能配餐，打通医疗机构临床健康管理与日常膳食，用低成本、高效率的方式为用户提供个性化营养方案，助力健康中国建设。

## ✨ 核心功能
- **AI 智能配餐**：根据个人身体状况、基础疾病、饮食偏好自动生成每日食谱
- **膳食参考标准**：融合国内膳食指南与国际公认的地中海饮食模式
- **医食互通**：连接医疗机构健康数据，实现临床健康管理和日常饮食联动
- **熊猫主题视觉**：柔和治愈的熊猫 IP，降低健康产品的距离感

## 🛠️ 技术栈
- **开发平台：JoyCode**
- **前端：网页 / App 应用**
- **智能能力：AI 膳食分析、营养计算**
